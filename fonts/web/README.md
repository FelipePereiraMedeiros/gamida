# Fontes da interface

Arquivos `.woff2` servidos pelo próprio Gamida para o app funcionar sem internet.
Foram obtidos do Google Fonts (a Pixelify Sans, do pacote @fontsource/pixelify-sans 5.3.0), apenas nos alfabetos usados (latino, grego e hebraico),
e são referenciados em `css/fonts.css`.
